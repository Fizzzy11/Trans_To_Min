# 正常242分钟通道号与四项基础数据口径修订

确认日期：2026-11-10。依据为用户本轮明确答复；本文件记录最新业务要求，优先于
此前分钟消费文档中冲突的通道号目标要求。本文件随框架1.2.2同步发布，但去通道号
及四项基础任务仍是待实施规范，不表示业务计算、机器规格、安装或历史结果已适配。
1.2.2仅实现默认关闭盘后折入；核心现有订单视图仍含通道号，本次不生成或覆盖数据。

## 一、适用范围与订单身份

正常242分钟的分钟消费不使用`channel`作为订单身份、订单对去重或多表关联键。
用户说明已测试跨通道同订单号仅发生于盘后交易。本范围排除15:00:00之后的记录，
15:00:00本身保留；必须在任何不含通道号的聚合、去重或关联之前排除这些记录。
不得先把含盘后交易的全日输入按无通道号键合并，再尝试裁掉盘后时间。

其余分钟规则沿用框架：上午09:30至11:30、下午13:00至15:00，共242个结束标签，
时区Asia/Shanghai。常规左开右闭；盘前事件纳入09:30；11:29之后至11:31（含）
归11:30；12:59至13:00（含）归13:00；14:59之后至15:00（含）归15:00。
其余午休记录不归分钟。本范围生成时应显式关闭盘后折入，即
`include_post_market=False`。1.2.1及以前默认True，1.2.2起默认False；业务仍应显式
声明口径，并在无通道号聚合／关联前过滤原始事件，不能仅靠聚合后的分钟映射。

正常分钟的完整订单身份为`trade_date、symbol、order_side、order_num`。
每分钟参与订单计数再加`minute`；买腿与卖腿分别使用自身订单号和固定订单方向，
不能用成交主动`side`覆盖订单方向。买卖订单对使用
`trade_date、symbol、minute、buy_order_num、sell_order_num`；买卖位置有序，不可互换。

本修订只约束分钟消费。三表物理`channel`仍保留，上游raw转三表匹配、来源核验及
历史编码仍按上游正式契约执行；不得因分钟不使用通道号而删除源字段或修改raw定价。

## 二、四任务管理、输入与输出

四项任务分别自包含，源码、包声明、README、generation_spec.json、生成及校验
入口、测试、指标说明、日志、锁和校验断点独立。不得以一个共同业务项目替代四项
任务的独立执行。只共享通用框架，正常执行不依赖其他三个任务先生成结果。

| 任务及主题目录 | 指标数 | 物理输入 | 生成读取次数／交易日 |
| --- | ---: | --- | ---: |
| wt_basic_min | 13 | weituo | 1 |
| cd_basic_min | 13 | chedan | 1 |
| cj_basic_min | 7 | chengjiao | 1 |
| acj_basic_min | 6 | chengjiao | 1 |

合计39项，四任务独立执行的生成读取合计4次／交易日；校验读取另计。每任务内部
通过MinuteMetricGroupRunner共享一次投影读取和必要中间量。不得将39项逐项读取，
也不将成交、主动成交跨任务只读一次作为本轮交付前提。

各指标独立保存`trade_date, minute, symbol, {metric_name}`四列，唯一键为前三列。
生产路径为`/sd1-data/trans_to_min/{任务}/{类别}/{metric_name}/{YYYY}/{YYYYMM}.parquet`。
类别目录具体名称尚待任务文档定稿，不能擅自删除该层级；39项指标名保留原图定义。
每项最终目录都包含非空README与独立manifest，禁止改为多指标宽表或每日生产文件。

逻辑输入按实际公式请求，通道号不在本轮四任务的必要计算字段中：

| 任务 | 逻辑字段并集 |
| --- | --- |
| wt_basic_min | symbol、time_ms、price、volume、money、side |
| cd_basic_min | symbol、time_ms、price、volume、money、side |
| cj_basic_min | symbol、time_ms、buy_order_num、sell_order_num、volume、money |
| acj_basic_min | symbol、time_ms、buy_order_num、sell_order_num、side、volume、money |

委托、撤单的money由适配器按还原后的片段price×volume派生，无价则为空；成交必须
使用源物理money。价格／金额按Parquet物理类型及metadata还原，数量单位股，价格
元／股，金额元；不另行按分舍入。数量及计数采用uint64，价格及金额采用float64。

## 三、统一记号、分钟范围与方向

以下公式均针对一只股票、一个交易日、一个分钟。E为按框架归入本分钟的合格
片段或真实事件集合；所有筛选必须先满足本文件第一节的时间边界。B、S分别为
委托／撤单订单方向49、50的子集。成交主动方向49、50、48分别表示主动买、主动卖、
未知；未知方向不在分钟层猜测，普通成交保留未知主动方向事件。

四任务的股票全集各取其声明物理输入当日实际出现的非空股票集合。成交与主动
成交均从未做主动方向筛选的成交输入确定股票全集；只有未知方向、没有主动买或
没有主动卖的股票仍补齐242分钟。四任务不额外查询股票池、停牌或ST信息，不取
四任务股票交集；全部事件被时间规则排除的输入股票仍按该指标空分钟规则补齐。

## 四、委托基础数据：片段事件口径

wt_basic_min明确以每条合格价格片段为统计单位，包含未能定价的合格片段。
同一订单、同一分钟两个片段计两笔；同价但属于两条真实片段也保留两笔，不能
按订单号、价格或时间去重。单、量、额和OHLC均按片段自身时间归分钟。

| 指标 | 公式或定义 |
| --- | --- |
| wt_op_min | 本分钟首个已知片段价格 |
| wt_hi_min | 本分钟已知片段价格最大值 |
| wt_lo_min | 本分钟已知片段价格最小值 |
| wt_cl_min | 本分钟最后一个已知片段价格 |
| wt_vl_min | Σ(E中各片段volume) |
| wt_mn_min | E中已定价片段price×volume之和，空值规则见第八节 |
| wt_bv_min／wt_sv_min | 分别Σ(B／S中各片段volume) |
| wt_bm_min／wt_sm_min | 分别累计B／S中已定价片段金额 |
| wt_td_min | E中片段条数 |
| wt_bd_min／wt_sd_min | 分别为B／S中片段条数 |

这修订了本轮此前已讨论的全日整单聚合后归最早锚点方案。该旧方案不再用于
wt_basic_min；已有信息熵、时间重心和极值业务仍按其实际已实现公式另行核对，
本轮不自动改变那些指标的统计单位或时间归属。

例一：同订单片段09:30:10、10元、100股，以及09:31:10、11元、200股：

| 分钟 | wt_td_min | wt_vl_min | wt_mn_min | OHLC |
| --- | ---: | ---: | ---: | --- |
| 09:31 | 1 | 100 | 1000 | 均为10 |
| 09:32 | 1 | 200 | 2200 | 均为11 |

例二：两片段都发生在09:30:10至09:31:00（含）内，数量分别100、200股，价格
分别10、11元。09:31计2笔、300股、3200元，最高11、最低10，开收取实际片段
时间及稳定行序的首末已知价。跨分钟不前移，同分钟也不合成一笔订单。

沪市缺原始A记录的补单只代表已经观察到的成交片段，本指标按这些实际片段计算，
不推导未知原始总量或未观察余量。市价恢复价与成交补片价不统称原始申报／排队价。

## 五、撤单基础数据：真实撤单次数

cd_basic_min对每次真实撤单单独计算；相同订单在同一分钟部分撤单、再撤剩余量，
计两次。即使订单号、时间、价格相同，真实不同撤单仍保留，不能按这些字段去重。
时间使用每次真实撤单时间，数量使用本次实际撤销量，不移到原委托时间。

13项cd指标与上节13项wt后缀逐项对应：op／hi／lo／cl为已知撤单价OHLC，
vl／bv／sv为真实撤销量求和，mn／bm／sm为各次已知撤单金额求和，
td／bd／sd为总／买／卖撤单事件条数。这里的“笔数”是撤单次数，不是不同订单数。

例：同一买单一分钟先撤100股、再撤剩余200股，价格均10元，则cd_td=2、cd_bd=2、
cd_sd=0、cd_vl=300、cd_mn=3000。第二次不再计原委托全部数量。两次都缺价时，
笔数与量仍为2和300，金额为NULL。

## 六、成交基础数据：双侧量额与订单对计数

普通成交E保留每笔真实事件及原时间，包括未知主动方向；不按订单对、价格或
同毫秒合并真实成交。买卖两腿分别累计同一事件的量额，所以两侧相等。

| 指标 | 公式或定义 |
| --- | --- |
| cj_bv_min／cj_sv_min | 两者均为Σ(E中原始成交volume)，每条原成交分别贡献给买、卖侧一次 |
| cj_bm_min／cj_sm_min | 两者均为Σ(E中原始成交money)，使用真实成交额 |
| cj_bd_min | 分钟内不同买方订单身份数量 |
| cj_sd_min | 分钟内不同卖方订单身份数量 |
| cj_td_min | 分钟内不同有序买卖订单对数量，不是两侧独立订单数之和 |

cj_bd与cj_sd中文名分别为买入成交笔数、卖出成交笔数，其统计单位在说明中明确
为分钟参与订单。cj_td中文说明为“总成交笔数（按不同买卖订单对计数）”。
不要求cj_td=cj_bd+cj_sd。订单计数仅在计数分支去重，不影响量额。

一买B1对应卖S1、S2、S3：买订单数1、卖订单数3、订单对3。相同B1/S1发生两次
真实成交：买1、卖1、订单对1，但两次量额全部累计。相同订单跨两个分钟参与，
每个分钟分别计数，不能全日只留首次。普通买卖量额不能相加后冒充单边市场总量。

零号、空号等非有效订单身份不得当成一个公共订单合并计数；先遵循正式来源契约
处理，未经定义的异常应报告，不能为方便计数静默删除真实成交量额。

## 七、主动成交基础数据：逐事件筛选，再按分钟计订单

令A买为E中原始side=49事件，A卖为E中原始side=50事件。必须先逐事件筛选，
再在所选事件内做订单计数；不能按订单首次方向、订单号大小或整单角色筛选全部成交。

| 指标 | 公式或定义 |
| --- | --- |
| cj_abv_min／cj_asv_min | 分别Σ(A买／A卖中原始成交volume) |
| cj_abm_min／cj_asm_min | 分别Σ(A买／A卖中原始成交money) |
| cj_abd_min | A买中不同买方订单身份数量 |
| cj_asd_min | A卖中不同卖方订单身份数量 |

极端但有效的角色转换例：卖一10元100股，买单B以10元申报300股，先主动吃掉
100股，余200股挂在买一；之后卖单S主动卖出200股成交于B。假设两次都为正常
时段真实成交，B订单号相同，第一笔side=49，第二笔side=50。

| 成交阶段 | 主动买量／额贡献 | 主动卖量／额贡献 |
| --- | --- | --- |
| B主动买100股 | 100股／1000元 | 0／0 |
| B被动买200股，由S主动卖出 | 0／0 | 200股／2000元 |

两笔在同一分钟时，cj_abd=1、cj_asd=1；跨分钟时分别归真实事件分钟。普通买、
卖量在整个例子范围内各300股，普通买、卖额各3000元。B的后200股绝不并入
主动买量额。同理，一个卖单先主动卖出、余量后来被动卖出，只有前者属于主动卖。

同一主动订单在一分钟内成交于多个对手：主动量额全计，主动订单只计1；若同一
订单部分事件主动、部分被动，只对主动子集统计量额和订单参与。同订单跨分钟的
主动事件每分钟独立计数。未知主动方向保留在普通成交，不进入两类主动指标。

## 八、价格顺序、缺价与空分钟

价格分支先按片段／事件时间排序，同毫秒按源文件行序稳定处理；源存储顺序不
保证真实消息先后，因此开收价的同毫秒顺序只承诺可复现，不冒充交易所消息序列。
开盘价、收盘价分别取首末已知价；最早片段缺价不要求开盘价为NULL，其他已知价
仍可形成OHLC。价格分支筛空不改变量与笔数。

| 对应指标统计组情况 | 价格 | 数量与计数 | 金额 |
| --- | --- | --- | --- |
| 真无合格事件 | NULL | 0 | 0 |
| 有事件且全缺价 | NULL | 正常保留 | NULL |
| 部分有价、部分缺价 | 用已知价格形成OHLC | 正常保留 | 只累计已知部分 |
| 已知金额为零 | 按真实已知价格处理 | 正常保留 | 0，不改为NULL |

委托与撤单的全缺价规则分别针对总／买／卖最终统计组，不能用另一方向的已知
金额使本方向全缺价组变成有效。成交真实价量额仍必须完整校验，不能因允许
委托／撤单缺价而放过成交缺失额。非空负额、Inf等仍按源契约拒绝，不静默过滤。

例：一分钟两委托片段，100股缺价、200股10元，计2笔、300股、已知额2000元，
OHLC均10；已知额不称完整估值。两片段都缺价则仍2笔300股，价格与金额NULL。

## 九、沿用边界与待落实事项

来源或源码变化拒绝无条件跳过；旧历史凭证不改写。独立校验须覆盖本次请求日期，
包括resume跳过日期，并验证读取次数、242分钟、Schema、NULL、唯一键及独立公式。

明确后才实施。本轮未创建或验收四任务计算项目，未按本目标修改核心订单视图、
