# Trans_To_Min 1.2.3 发布说明

发布日期：2026-11-11。本次是适配器正确性与指标组性能的小版本修正，不运行生产数据任务。
来源：四类基础分钟（wt/cd/cj/acj_basic_min）提速与交叉评审中确认的、适用于所有基于本框架的
逐笔转分钟业务的两项改动（框架改动建议第1、3项）。

## 一、已实现的修改

### 1. 适配器转无符号整数前校验（正确性）

`volume`、`order_num`、`buy_order_num`、`sell_order_num`原来直接
`pd.to_numeric(...).astype("uint64")`：-5 静默变为 18446744073709551611，1.7 静默截断为 1，
空值抛出 `IntCastingNaNError`。业务层在适配器之后无法区分“真实极大值”与“负数绕回”。

现在：

| 来源物理类型 | 处理 |
| --- | --- |
| 无符号整数（当前正式三表为 uint32 非空） | 直接转 uint64，零额外检查，结果不变 |
| 有符号整数、可空整数、布尔 | 空值或负数报 `ValueError` |
| 浮点 | 空值、非有限值、负数、小数或 ≥2^64 报 `ValueError` |

错误信息含“数据集.字段”和原因（空值/负数/小数/非有限/超出范围）。

### 2. `finalize_aggregated_day` 接收可选股票全集（性能）

`MinuteMetric.finalize_aggregated_day(trade_date, inputs, aggregated, symbols=None)`。
原实现每个指标都对完整输入调用 `symbol_union`（整表 dropna/unique），组内 13 个指标就扫 13 次。
指标组可先算一次全集再传入：

```python
symbols = group_metrics[0].symbol_union(inputs)  # 全组输入相同时只算一次
for metric in group_metrics:
    yield metric, metric.finalize_aggregated_day(trade_date, inputs, sparse[metric.name], symbols=symbols)
```

传入值必须等于 `symbol_union(inputs)`：本指标声明的全部输入中实际出现的非空 symbol，先于时间
及方向筛选（只有盘后记录的股票也在内）。框架会去重、排序并拒绝空值，但不会再扫描输入核对，
正确性由调用方负责，全集必须来自完整、未筛选输入。不传 `symbols` 时行为与 1.2.2 完全相同。
这是自定义共享计算显式选择的性能接口；默认`MinuteMetricGroup`仍逐指标调用`compute_day()`，
不会自动缓存或传入全集，也不承诺默认指标组自动提速。

## 二、保持不变

- 242 个分钟标签、盘前/午休/收盘边界、`include_post_market` 默认 False。
- 输入根 `/sd1-data/level2`、输出根 `/sd1-data/trans_to_min`、主题/类别/指标/年份/月文件层级、四列 Schema。
- 金额、价格的缩放与 NULL 规则，订单视图及 channel 键，并行与月度发布、标准任务入口及来源门禁。

## 三、升级与历史结果

- 框架源码参与逐指标逐日来源契约：1.2.2 生成的结果不能直接 resume 为 1.2.3，旧凭证不改写。
- 正式三表中本次涉及的数量和三个订单号字段均为uint32非空，合法输入读取结果不变；
  其他来源中的非法值由静默绕回／截断改为明确报错。
- 业务层此前为兜底绕回所加的“单事件数量 ≥2^63 拒绝”可以保留，但只是单事件异常兜底，
  不能保证多个合法事件的分组和不溢出；分组求和仍须独立检测溢出，不改变业务公式。
- 1.2.3只升级框架、测试和文档，不读取、生成或重算生产数据。
  安装和部署实际状态以独立验收记录为准，不能从源码版本推断服务器已升级成功。

### 安装元数据刷新与部署核对

可编辑安装能直接看到源码更新，但旧安装元数据可能仍是1.2.2；正式部署须使用已有依赖
刷新安装元数据，例如在服务器授权范围内执行以下命令，再同时核对导入位置、运行时版本及元数据：

```bash
/app/workspace/zhangyuan/.venv/bin/python -m pip install --no-index --no-deps --no-build-isolation -e /app/workspace/zhangyuan/Trans_To_Min
/app/workspace/zhangyuan/.venv/bin/python -c "import trans_to_min; from importlib.metadata import version; print(trans_to_min.__file__, trans_to_min.__version__, version('trans-to-min'))"
```

以上为部署操作与核对要求，不代替独立部署验收记录；元数据应与运行时同为1.2.3。安装成功也不能
使旧契约直接resume，不改写旧凭证，不因升级自行重算历史。

### 永久回归范围

新增`tests/test_adapter_unsigned.py`，使用`tmp_path`、标准`input_path`、`pa.table`与
`pq.write_table`写真实临时Parquet，再经公开`L2InputAdapter.read`读取，不mock适配器或Parquet。
四个字段分别验证uint32/uint64/int64/float64/布尔、空列、高位整数精确值与事件行序；
非法负数、小数、NaN/Inf、float64的2^64上界、三类可空物理整数及uint64最大值含NULL均应
报含实际`dataset.field`的`ValueError`。显式股票全集回归保留仅盘后股票，并验证排序、去重与默认结果等价。
