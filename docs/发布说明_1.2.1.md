# Trans_To_Min 1.2.1 发布说明

发布日期：2026-11-05。本次是默认输出位置的小版本调整，不改变计算或数据结构。

## 修改范围

- `RunConfig.output_root`默认值由`/data/zhangyuan/trans_to_min`改为
  `/sd1-data/trans_to_min`。
- 框架参考入口`scripts/run_trade_volume.py`采用相同新默认值。
- 同步版本元数据、当前文档和默认路径回归测试。

正式业务文件仍按以下模式保存：

```text
/sd1-data/trans_to_min/{主题}/{类别}/{指标}/{年份}/{年月}.parquet
```

例如：

```text
/sd1-data/trans_to_min/entropy_min/vol_entropy_min/cj_vol_entropy_min/2026/202609.parquet
```

主题和类别由业务入口配置；通用执行器只在其收到的输出目录下追加
`{指标}/{年份}/{年月}.parquet`，不自动推断或新增目录层级。
每个Parquet仍为`trade_date, minute, symbol, {metric_name}`四列。

## 保持不变

- 逐笔输入根目录仍为`/sd1-data/level2`。
- 保持242分钟轴、股票规则、NULL语义、业务公式、并行计算和月份原子发布逻辑。
- 显式配置的`output_root`或`--output-root`继续优先，不被新默认值重定向。
- 1.2.0标准任务入口仍要求显式传入输入、输出和结果JSON路径；不会因本次修改
  而允许省略`--output-root`，全量/日更/修订流程不变。
- 暂存、manifest和标准入口锁仍按原规则跟随实际传入的输出目录。

## 部署与使用边界

本次只更新通用框架，不迁移已有数据，不创建`/sd1-data/trans_to_min`，不修改
目录权限，不生成生产数据，也不改信息熵、时间重心、maxdiv及下游因子的独立脚本。
这些业务入口已有的显式旧路径不会因公共框架升级而自动切换。

启用新默认值前，需要授权人员另行准备目标目录及权限。本框架不自动配置共享
访问权限，也不在新目录不可写时静默回退旧目录。历史正式数据是否迁移、下游是否
切换，须独立记录；不能从框架安装版本推断数据位置。

框架版本及核心源码参与逐日期来源契约，因此请求旧版已生成日期时，resume可能
因身份不匹配而拒绝。不得把历史凭证改写成1.2.1或擅自重算以通过门禁；仅追加新日
不要求重算未请求的旧日。旧日期保持原生成版本，本次不是一次历史重建。

发布提供核心wheel和`SHA256SUMS.txt`；业务模板、文档和测试从对应源码标签获取，
不包含在核心wheel内。服务器切换前须检查相关活动进程并保留原安装备份。
